## Plan

Baseline (branch from `origin/main` d3673dd, Node 22.22.0): lint clean,
`npx vitest run` 10 files / 159 tests.

1. `src/starter.js` (new, no dependencies beyond node built-ins):
    - `validateStarterSpec(spec)` — bare name, package name (`@scope/x`,
      unscoped `nera-starter-x` / any lowercase npm name), GitHub URL
      (`https://github.com/o/r[.git][#ref]`, `github:o/r[#ref]`), local path
      (`LOCAL_THEME` shape). Anything else throws naming the four forms.
    - `starterSource(spec)` → `{ kind: 'local', path }` or
      `{ kind: 'npm', spec }` where bare → `@nera-static/starter-<name>` and
      GitHub forms → `github:o/r[#ref]`.
    - `packStarter(source)` — `npm pack <spec> --ignore-scripts
      --pack-destination <tmp>` + `tar -xzf` into a temp dir; returns
      `{ dir: <tmp>/x/package, cleanup }`, temp dir removed on failure.
    - `fetchStarter(spec, { cwd, pack })` — local path read in place (no-op
      cleanup); otherwise calls the injectable `pack`.
    - `readStarterManifest(dir, spec)` — refuses a dir without
      `nera.starter`.
    - `applyStarter(targetDir, starterDir)` — copies only `pages/`,
      `config/`, `theme/`, `assets/`, `plugins/`, `.neraignore` (starter
      wins), merges `dependencies` (never `@nera-static/nera`), returns the
      README text or null.
    - `listStarters({ fetch })` — registry search, 3 s timeout, official
      first then alphabetical; bundled `src/starters.json` on any failure.
2. `src/scaffold.js`: `setAppValue(yaml, key, value)` (line-based, exported),
   `validateSiteName`/`validateLang`; `scaffoldProject` takes `starter`,

   starter manifest (before the target exists, so a non-starter leaves
   nothing) → base template (skip scaffold-default views if the starter's

   README after Done. Failure after creating the folder removes it (not in

3. `src/prompt.js` (new): `shouldPrompt`, `ask(rl, question, default)`,

   `--lang` (both forms), `--yes`; picker only on TTY without `--yes` /

4. `bin/nera.js` usage, `README.md` (command table + "Starter kits").
